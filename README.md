# Moved

The retro 70s tiles, theme and wallpapers for cleanyourtv now live in a fork of cleanyourtv, on its `retro` branch:

**https://github.com/michaelhalstead/cleanyourtv/tree/retro/retro70s**

There the tiles are built into the launcher, so there is no copy step, and the branch keeps up with upstream
cleanyourtv. This repository is archived and no longer updated.
